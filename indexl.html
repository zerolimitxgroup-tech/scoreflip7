How to Play

\ \
\
\

Goal

\

Be the first player to reach 200 points across multiple rounds. Each round, you draw cards trying to build a high score \'97 but draw a duplicate number and you bust, scoring nothing.

\ \

On Your Turn

\

Hit \'97 draw another card. Stay \'97 stop and lock in your points for the round.

\ \

The Deck

\

This isn't a normal deck. There's only one 1, two 2s, three 3s, all the way up to twelve 12s. Higher cards are more common \'97 but also more likely to bust you.

\ \

Busting

\

If you draw a number card that matches one already in front of you \'97 you bust and score zero for the round.

\ \

Flip 7 Bonus

\

If you collect 7 different number cards, you score a +15 point bonus and the round ends immediately for everyone.

\ \

Scoring

\
\
Normal Mode
\

Add up your number cards. Apply \'d72 to the number sum if you have it. Then add any + modifiers. Finally add +15 if you flipped 7.

\
\
\
Vengeance Mode Vengeance
\

Add up your number cards (0\'9613). Apply \'d72 or \'d73 if you have it. Then apply \'f72 (round down). Then subtract any negative modifiers (score can't go below 0). Then add positive modifiers. Finally add +15 if you flipped 7.

\
\ \

Vengeance Mode Cards New

\
\
Number Card: 13
\

13 cards with value 13 are added to the deck \'97 high reward but high bust risk.

\
\
\
Negative Modifiers: \uc0\u8722 2, \u8722 4, \u8722 6, \u8722 8, \u8722 10
\

These reduce your score. Applied after \'f72 but before positive modifiers.

\
\
\
\'f72 Modifier
\

Cuts your number card total in half (rounded down). Applied before negative modifiers.

\
\
\
\'d73 Modifier
\

Triples your number card sum. Works like \'d72 but bigger.

\
\ \

Winning

\

When at least one player reaches 200 points (or your custom target), the round finishes and the player with the highest score wins. Ties share the victory.
